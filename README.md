# PienoFvg

PienoFvg is a modern web application developed with Blazor that allows motorists to compare fuel prices in real time between Italy and Slovenia. The application provides a comprehensive overview of gasoline and diesel prices at various fuel stations, enabling users to identify the most cost-effective options.

In addition to current price comparisons, PienoFvg offers forecasts on future price trends based on market analysis, helping users plan their refueling strategically. The system uses an algorithm that correlates crude oil prices with pump prices, taking into account fiscal and seasonal factors specific to each country.

The application is designed following SOLID principles and implements several design patterns to ensure a scalable and easily extensible architecture, ready to integrate data from additional Italian distributors in the future.

With an intuitive and responsive user interface, PienoFvg is an essential tool for those looking to optimize their fuel expenses, especially useful for residents in border areas and for frequent travelers between Italy and Slovenia.
